# XR-sääntelybotti: Annan linjaukset (10.11.2026)

- Kohderyhmä: julkinen, ensisijaisesti Suomessa olevat kehittäjät ja tutkijat.
- Kieli: suomi ja englanti. Botti vastaa käyttäjän kielellä.
- Vastaus: suositukset, lähdeviitteet ja perustelu, miksi juuri nämä valittiin.
- Lähteet: aina ensisijaiset sivustot (EUR-Lex, Finlex, standardin julkaisija). EU-säädöksissä myös Suomen viranomaisten tulkinnat (esim. Traficom).
- Kysymyspolkuun: käyttäjän markkina-alue (Suomi / Eurooppa / maailmanlaajuinen). Yhdysvaltojen sääntely voi poiketa EU:sta.
- Alusta: oma web-sovellus Claude API:n päälle (vaihtoehto C), tietopohja repossa `sources/`.
- Lähtöaineisto: https://annaelo.github.io/XR-vuosi-2026/#standardit (data repossa AnnaElo/XR-vuosi-2026, index.html).
